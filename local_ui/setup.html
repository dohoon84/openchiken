Telegram 봇 설정

@BotFather → /newbot → 토큰 발급

@userinfobot에 메시지를 보내면 내 Telegram ID를 알 수 있습니다. Telegram · Discord · Slack 모두 이 목록을 공유합니다.

Slack 봇 설정

Slack App → OAuth & Permissions → Bot User OAuth Token

Slack App → Settings → Socket Mode → App-Level Token 발급

Discord 봇 설정

discord.com/developers → Bot 탭 → Reset Token → 복사

Discord 설정 → 고급 → 개발자 모드 ON → 본인 이름 우클릭 → 사용자 ID 복사
⚠️ Application(Client) ID가 아닌 본인 계정의 User ID를 입력하세요.

warning

Bot 탭 → Privileged Gateway Intents → Message Content Intent를 반드시 ON으로 설정하세요.

iMessage 설정 (macOS 전용)

lock_open

전체 디스크 접근 권한 필요

iMessage 수신을 위해 ~/Library/Messages/chat.db 읽기 권한이 필요합니다. macOS 보안 정책상 이 권한은 반드시 사용자가 직접 부여해야 합니다.

  1. 1아래 버튼을 눌러 시스템 설정을 엽니다
  2. 2개인정보 보호 및 보안 → 전체 디스크 접근으로 이동합니다
  3. 3+ 버튼 → Terminal.app (또는 Python 실행 앱) 추가 후 잠금 해제

✓ 시스템 설정이 열렸습니다. 수동으로 권한을 추가하세요.

전화번호(+82 국가코드 포함) 또는 Apple ID 이메일. 여러 개면 쉼표로 구분합니다.
