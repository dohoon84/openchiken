스킬 시스템 SKILL.md 기반

OpenClaw/AgentSkills 호환 스킬 아키텍처. 각 스킬은 SKILL.md(AI 지시) + tool.py(구현)로 구성됩니다.
~/.openchiken/skills/에 폴더를 추가하면 다음 실행 시 자동으로 로드됩니다.

동적 로딩 사용자 확장 OpenClaw 호환
~/.openchiken/skills/my_skill/
─ SKILL.md # AI 지시 + 메타
─ tool.py # LangChain 도구
# SKILL.md 예시
---
name: my_skill
enabled: true

Autonomous Engine

복잡한 작업도
알아서 계획하고 실행

Plan-and-Execute 엔진이 복잡한 요청을 단계별로 분해합니다. 각 단계를 실행하면서 결과를 평가하고, 필요하면 계획을 수정하여 최적의 답변을 도출합니다.

01

Planner

요청을 분석하여 구체적인 실행 단계를 생성합니다.

02

Executor

각 단계를 도구(Gmail, Calendar 등)를 활용하여 실행합니다.

03

Replanner

결과를 평가하고, 미완료 시 계획을 동적으로 수정합니다.

1

사전 준비

Python 3.11+ 와 uv 패키지 매니저가 필요합니다.

$ curl -LsSf https://astral.sh/uv/install.sh | bash
2

설치 git clone 불필요

한 줄로 설치하면 openchiken 명령이 전역으로 사용 가능합니다.

$ uv tool install git+https://github.com/dohoon84/openchiken.git

$ openchiken-setup
